# Передача Chvilio независимому аудитору

Снимок подготовлен 24 ноября 2026 года. Продуктовый baseline — main
`194757836493bf0abcd396612927b5aa813c1435`, включая иконку из PR #153.
Этот пакет передаёт контекст и план проверки. Итоговую оценку готовности должен
получить Claude Code по собственным проверкам.

## Запуск

1. Открой Claude Code в корне этого репозитория.
2. Передай ему целиком содержимое [FIRST-PROMPT.md](FIRST-PROMPT.md).
3. Для локальных интеграционных проверок запусти Docker Desktop. Claude проверит
   доступность сам. Доступы к платным провайдерам для локального аудита не нужны.
4. После аудита начни с `artifacts/independent-audit/FINAL-REPORT.md` и
   `artifacts/independent-audit/readiness.json`.

## Границы полноты

В JSON сохранены все доступные при сборке 158 неархивированных задач команды
Linear, 153 полученных PR, 219 достижимых коммитов baseline с путями файлов,
67 миграций и 45 литеральных RPC-обращений в app/package исходниках.
Описания задач из списка могут быть обрезаны Linear. Это явно помечено в каждой
записи. Для восьми ключевых задач добавлены полные описания.
Архивированные задачи, недоступные PR, обсуждения и комментарии не выгружались.
Количество реально полученных записей хранится в `metadata`.

Продуктовые предпочтения из общения владельца собраны в `PRODUCT.md` и
`decisions` JSON. Полной стенограммы разработки у пакета нет. Ссылки на PR,
задачи, миграции и документацию позволяют восстановить детали доступных решений.
Папки `.superpowers/`, локальные изображения из переписки, `.env` и сторонние
аккаунты не являются обязательной частью передачи.

## Как читать доказательства

Для каждого утверждения разделяй намерение владельца, наличие реализации,
собственный результат теста и проверку развёрнутого окружения. Green CI относится
к определённому коммиту и среде. Иконка, splash и EAS-профиль добавлены в main,
но подписанная сборка и установка на iPhone этим не подтверждены.

Наблюдение hosted Supabase от 11 ноября находится в
`docs/operations/pilot-release-acceptance.md`. Его надо обновить при новом
разрешённом обследовании. Покупка Apple Developer была намерением владельца
16 ноября. Подтверждения её завершения в этом снимке нет. Последнее сообщение
владельца сообщало об отсутствии домена и настроенной доставки Resend, а также
об использовании базового тарифа Supabase.

## Найденные расхождения источников

- README ещё говорит, что бренд не выбран. Владелец утвердил Chvilio,
  переименование и иконка присутствуют в main.
- `docs/architecture/monorepo.md` содержит ранние формулировки об отсутствии
  интеграции API и предполагаемые UI-пакеты. Сверяй с `packages/*/package.json`.
- Центральный документ Linear обновлён 9 сентября. Там упомянуты три языка,
  будущие Expo Router/TanStack Query и отложенные recurring visits. Реализация
  позднее расширилась до пяти языков и повторяющихся визитов.
- SCH-57 и SCH-157 помечены Done в Linear, но их критерии и сохранённые
  acceptance-документы оставляют непроверенные native/hosted сценарии.
- SCH-100 Done соседствует с открытыми SCH-146/SCH-159 по реальной доставке.
  SCH-155/SCH-156 остаются Backlog, хотя часть кода и локальных проверок готова.
- `backend-release.md` содержит исторический inventory двух функций от
  20 октября. Нынешний deploy workflow развёртывает четыре функции.

Сохрани эти противоречия как вопросы сверки. Находки в работающем продукте
подтверждай отдельно. Пакет намеренно не исправляет статусы за аудитора.

## Поиск в базе

```sh
python3 docs/audit/claude-handoff/build_database.py --check
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s docs/audit/claude-handoff -p 'test_*.py'
sqlite3 docs/audit/claude-handoff/audit-context.sqlite \
  'select id, status, title from linear_issues where status != "Done";'
sqlite3 docs/audit/claude-handoff/audit-context.sqlite \
  'select number, title from pull_requests order by number desc limit 12;'
sqlite3 docs/audit/claude-handoff/audit-context.sqlite \
  'select id, title, status from gaps;'
```

Если `sqlite3` CLI отсутствует, используй стандартный модуль Python `sqlite3`
или читай JSON. Секреты для запросов к этой базе не требуются.
